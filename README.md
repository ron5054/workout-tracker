# המכונות שלי

אפליקציית Vite + React לניהול אימוני כושר לפי מכשיר. כל כרטיס מציג תמונה של המכשיר ואת **המשקל האחרון** שעשית עליו. הנתונים נשמרים ב-`localStorage` בלבד, והאפליקציה עובדת כ-PWA שאפשר להתקין בטלפון.

## מה יש בפנים

- 12 התרגילים שלך: פולי עליון, פולי חתירה, יד אחורית/קדמית בפולי, 4 ראשי ישיבה ושכיבה, חזה סמית׳/דאמבלס/פלייס, בטן על בוסו, כתפיים סמית׳, וחתירת גב ברכינה
- תמונות מכשירים מהאינטרנט (קישורים, בלי הורדה לפרויקט)
- רישום מהיר של משקל, חזרות וסטים
- היסטוריה לכל מכשיר, כולל השוואה לסט הקודם
- סינון לפי קבוצת שרירים
- ממשק עברית מימין לשמאל

## הרצה מקומית

```bash
npm install
npm run dev
```

השרת עולה על פורט `43170`.

בנייה לפרודקשן:

```bash
npm run build
npm run preview
```

## התקנה כ-PWA

בדפדפן בטלפון: תפריט → **הוספה למסך הבית**. אחרי הביקור הראשון התמונות נשמרות במטמון כדי שיטענו גם כשהרשת חלשה.

## נתונים

הכל נשמר במכשיר תחת המפתח `gym-tracker:logs:v1`. אין שרת ואין חשבון. מחיקת נתוני האתר בדפדפן תמחק גם את ההיסטוריה.
